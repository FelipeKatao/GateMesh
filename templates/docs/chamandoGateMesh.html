Realizando chamadas ao GateMesh

Conectando seu serviço com o GateMesh

O GateMesh se conecta com a s suaaplicação atraves de uma chamado HTTP a API do Gatemesh

Ao Colocar o codigo de chamada na sua aplicação o GateMesh vai ser capaz de chamar o codigo e assim realizar o tartamento para redirecionar ao serviço destino atraves da configuração dentro do GateMesh ( que será abordada mais para frente)

Configurando o GateMesh Monitor

A Rota que faz a chamada ao GateMesh Monitor é a seguinte:


                RouteCall = "http://localhost/_gateway/service/users"
                Header = {"service": "name","method":"GET", "role": "admin","token":"XXXX","userToken":0000,"app":"name","config_register": config}
                //Realizar chamada Http

Dentro da chamada é necessario enviar parametros importantes atraves do Header da chamada, cada um desses parametros é necessaria para fazer funções especificas ou para conseguir realizar o tratamento da chamada.
Abaixo uma explicação para que serve cada um desses parametros:

  • service: Nome do serviço que deseja realizar a chamada
  • method: Metodo que deseja realizar a chamada (GET,POST,PUT,DELETE)
  • role: Permissão que deseja realizar a chamada (admin, user, guest)
  • token: Token que deseja realizar a chamada para realizar a autenticação da sua aplicação com a aplicação destino.
  • userToken: Token que deseja realizar a chamada para fazer autenticação de permissão do usuario
  • app: Nome da aplicação que deseja realizar a chamada
  • config_register: Configuração do projeto

Configurando GateMesh Monitor

Após criar a rota para chamada agora é necessario, configurar o Monitor para ser capaz de entender qual serviço o cliente estará usando dentro da sua aplicação para que isso seja possivel, dentro da aba Parâmetros > Configuração GateMesh , deverá configurar quais serviços o sisetma estara usando para realizar as chamadas e em endereço ele esta alocado: 


            gateway:
            host:0.0.0.0
            port:8000
            routes:
                -name:NomeService
                path:/
                target:http://localhost

As primeiras linhas são a configuração geral do Gatemesh podendo configurar qual porta e qual host ele está localizado para ser executado no computador local ou em servidores.

Criando parametros

Dentro dde Parâmetros > Parâmetro do sistema, crie a CHAVE que vai ser usada para autenticar a sua aplicação com o GateMesh desta maneira permitindo a aplicação de executar as rotas e serviços do GateMesh. 

                    chave: appttoken_nomeProjeto
                    Valor: XXXX

Lembre-se que para a chave para ser valida para autenticação ela deve Sempre começar com "appttoken_" sem isso o sistema não consegue localziar a sua chave de conexão com o GateMesh.

Executando o serviço

Agora quando for executar a sua rota configurada para o GateMesh ela vai ser capaz de realizar o tratamento para redirecionar ao serviço destino.
Ainda não temos a configuração de redirecionamento,LoadBalance ou politicas, mas isso vai ser abordado mais para frente.

Fazendo upload do GateMesh Code para o GateMesh Monitor

Para que o GateMesh reconheça seu sistema e realize as chamadas ao GateMesh Monitor, basta fazer o upload do GateMesh Monitor para o GateMesh Monitor, para fazer isso o usuario precisa subir o arquvivo .gmc atraves da rota HTTP seguindo esses parâmetros: 

                    with open('config_server.gmc') as f:
                        config = f.read()   
                    RouteCall = "http://localhost/_gateway/service/upload"
                    Header = {"service": "name","method":"GET", "role": "admin","token":"XXXX","userToken":0000,"app":"name","config_register": config}
                    ...
No lugar de SUA CONFIGURAÇÃO deverá colocar a configuração do GateMesh Monitor, no exemplo acima utiliamos python para isso, mas caso utilize outra linguagem segue a mesma logica, faça a leitura do arquivo .gmc e coloque a configuração dentro da variavel "config" atraves do tipo str (string).
Nesse primeiro momento pode subir esse arquivo vazio depois poderá subir novamente atualziando o arquivo com a configuração atualizada.
